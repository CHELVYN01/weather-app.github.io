# 🌦️ Weather App - Cuaca Online

[![GitHub Pages](https://img.shields.io/badge/GitHub-Pages-blue)](https://chelvyn01.github.io/weather-app.github.io/)

Weather App adalah aplikasi cuaca berbasis web yang memungkinkan pengguna untuk mencari informasi cuaca di berbagai lokasi secara **real-time**. Aplikasi ini menampilkan **suhu saat ini, kondisi cuaca, dan prakiraan cuaca untuk beberapa hari ke depan**.

---

## 📌 **Teknologi yang Digunakan**
Proyek ini dibangun menggunakan teknologi modern berikut:

- **HTML** → Struktur halaman web.
- **CSS (Flexbox & Media Queries)** → Styling responsif untuk tampilan di desktop, tablet, dan HP.
- **JavaScript (ES6+ & Fetch API)** → Mengambil data cuaca dari API dan memprosesnya.
- **WeatherAPI** → Sumber data cuaca real-time.
- **GitHub Pages** → Hosting gratis untuk aplikasi berbasis statis.

---

## 🔥 **Fitur Aplikasi**
✅ **Cari cuaca di lokasi mana pun** 🌍  
✅ **Tampilkan suhu, kondisi cuaca, dan ikon** ☀️🌧️  
✅ **Prakiraan cuaca hingga 3 hari ke depan** 📅  
✅ **Deskripsi cuaca otomatis diterjemahkan ke Bahasa Indonesia** 🇮🇩  
✅ **Tampilan responsif untuk HP, tablet, dan desktop** 📱💻
